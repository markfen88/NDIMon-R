Security
Additional host names

The device's IP addresses, its hostname, hostname.local and names in its own DNS domain always work. Add any other name you use, such as a DNS alias; the device refuses names it does not know to protect the login.

Network
Networks

NDI and Tessera assignments are changed in their respective control panels. Several services can share a network. An unavailable network keeps its assignments.

Add or edit a network

Tagged VLANs require a switch trunk carrying those IDs. Untagged follows the switch port’s native VLAN; it does not imply VLAN 1. This list shows networks configured on this appliance.

Changes can interrupt network access. Keep them within 60 seconds after they are applied, or the previous configuration is restored.
